# Aim OTS Toggle Demo (External Mods v3)

What this demo does:
- Registers an aim camera profile for `cup`, `bow`, `hookshot`, and `slingshot`.
- Auto-binds keyboard `F8` to `MOD_ACTION7` using `defaultKeyboardKeys`.
- Toggles first-person <-> OTS through `toggleAimCameraMode`.

How to test:
1. Copy this folder to `x64/Release/mods/aim_ots_toggle_demo`.
2. Launch the game and enable the mod.
3. Enter any aim mode (`C-Up`, bow, hookshot, slingshot).
4. Press `F8` to toggle OTS.
