# Shield Skate Demo

Demonstrates:
- `movement.profiles.v1`
- `world.queries.v1` capability declaration
- `items.use_profiles.v1`

Use the item to toggle `mode: "surf"` movement.

Behavior:
- escudo físico sob os pés durante todo o surf
- idle em `stand` quando velocidade ~0
- aceleração em descida, freio em subida, drag em plano
